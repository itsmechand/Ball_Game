# Ball Game 🎮

A simple browser game where you guide a ball through moving lines.

## How to Play

1. Click "Start Game"
2. Use LEFT and RIGHT arrow keys to move
3. Pass through the gaps in the lines
4. Don't hit the lines!

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
